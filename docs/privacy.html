Privacy Policy – Kalila Channel Manager

Last updated: 2 November 2026

Kalila Channel Manager is a private tool used only by Mehdi Rahmani to manage his own YouTube channels (Kalila & Dimna, The Guest House and related channels). It is not offered to the public.

What it accesses. With the channel owner's permission (Google OAuth), it uses the YouTube Data API and YouTube Analytics API to upload and edit videos, captions, thumbnails and playlists, reply to comments, and read channel statistics for the owner's own channels.

What it stores. Only the OAuth tokens needed to act on the owner's channels, kept in private, access-controlled storage. Analytics summaries may be kept in the owner's private notes. No data about viewers is collected, sold or shared with third parties.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions.

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
